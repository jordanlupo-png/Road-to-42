# Road to 42

A mobile-first gamified endurance training MVP.

## MVP features
- Eight selectable animal runners with five visual evolution stages
- Character progression shown on the dashboard, account and community leaderboard
- Goal-event countdown
- 1 km = 1 XP progression
- Multi-gate levels: cumulative distance, endurance, consistency and speed
- Weekly check-in with km, pace, longest run, sessions, fatigue, soreness and sleep
- Training-readiness score kept separate from game XP
- Individual level race / competitor view
- Achievement system
- Supabase accounts and cloud-synced progress
- Responsive, installable-web-app foundation

## Important design principle
The app should not encourage athletes to run easy sessions faster merely to gain levels. Weekly average pace is displayed as a useful statistic, while future versions should use designated benchmark sessions for speed gates and personalize thresholds from onboarding.
